# Atlas and Wiki

Atlas is its own Shizuha application at https://shizuha.com/atlas/. Sign-in is Shizuha ID. The storefront at `/apps/shizuha/atlas/` opens that application.

Wiki does not host the Atlas screen, the catalog, or the map API. A page that already contains an Atlas document still shows it: the fence is sent to `/atlas/embed` in the same browser session. Page collaboration for a document that remains on a Wiki page stays a Wiki concern. New maps are created in Atlas and belong to an organization there.
